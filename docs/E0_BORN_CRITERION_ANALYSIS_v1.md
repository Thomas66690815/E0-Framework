# E₀ Born Criterion Analysis
## Does normalized intensity become structurally mandatory?

**Status:** Research note / criterion analysis  
**Date:** 2026-03-23  
**Language:** English  
**Purpose:** Determine whether the normalized square-modulus of E₀ endpoint amplitudes is merely available, or whether it becomes structurally mandatory under explicit realization conditions.

---

## 1. The exact question

We now have a structurally motivated endpoint intensity:

```text
I(z) = |Ψ(z)|²
```

where:

```text
Ψ(z) = Σ_{p→z} exp(-S(p)) exp(iΘ(p))
```

The question is no longer whether `I(z)` is mathematically natural.
That is already clear.

The stricter question is:

> If a transition episode presents a bounded set of mutually exclusive endpoint alternatives, does E₀ force the realization weight to be the normalized intensity
>
> ```text
> P(z) = I(z) / Σ_w I(w)
> ```
>
> or is that only one optional interpretation among others?

This note argues that **Born-like normalization is not yet globally forced in unrestricted E₀**, but **it becomes the uniquely natural candidate inside a specific realization regime**.

That distinction is decisive.

---

## 2. What would have to be true for a Born-like rule

A normalized intensity rule can only be structurally justified if all of the following are true.

### 2.1 Finite or summably bounded alternative set

There must be a well-defined comparison class of endpoints:

```text
Ω = {z1, z2, ..., zn}
```

or a countable family with finite total intensity.

Without this, normalization is undefined.

### 2.2 Mutual exclusivity of realization

A single realization episode must culminate in **one** endpoint from `Ω`, not several simultaneously.

Otherwise normalized weights are not selection weights.

### 2.3 Representation invariance

The realization weight assigned to an endpoint should depend only on the physically/structurally meaningful amplitude object, not on arbitrary representation choices such as global phase.

### 2.4 Monotonicity with endpoint support

If one endpoint has strictly stronger coherent support than another, the realization weight should not decrease.

### 2.5 Consistency under regrouping / coarse graining

If alternatives are partitioned and recombined, the weight rule should behave coherently rather than changing arbitrarily under redescription.

If these five conditions hold, the field of admissible candidate rules shrinks sharply.

---

## 3. Why raw amplitude cannot be the rule

Could the realization weight be proportional to `Ψ(z)` itself?
No.

Reasons:

1. `Ψ(z)` is complex-valued, so it is not an immediately valid scalar weight.
2. It is not invariant under global phase change.
3. Its real part or imaginary part can be negative.

Therefore the raw amplitude is not a structurally acceptable endpoint weight.

So some scalarization is necessary.

---

## 4. Why plain modulus is also insufficient

Could the rule use:

```text
|Ψ(z)|
```

instead of `|Ψ(z)|²`?

This is better than raw amplitude, but still weaker than the square modulus.

### 4.1 Positivity

Yes, `|Ψ| ≥ 0`.

### 4.2 Phase invariance

Yes.

### 4.3 But additive composition becomes awkward

The square modulus naturally exposes bilinear interference structure and behaves correctly as the norm induced by the complex carrier.
The plain modulus lacks this cleaner quadratic decomposition.

### 4.4 Coarse-graining problem

Norm-squared is the canonical scalar compatible with Hilbert-style amplitude addition. Plain modulus does not generally preserve the same clean additivity under decomposition into noninterfering sectors.

So `|Ψ|` is possible as a monotone scalar, but it is not the most structurally stable one.

---

## 5. Why the square modulus is privileged

Once `Ψ` is the carrier, `|Ψ|²` is privileged because it is simultaneously:

- positive,
- phase-invariant,
- quadratic in a way that retains interference,
- naturally additive over orthogonal/noninterfering decomposition,
- and induced directly by the complex carrier norm.

That is a powerful package.

It means that even before normalization, `I(z)=|Ψ(z)|²` is not just one scalar among many.
It is the **canonical support scalar** generated by the amplitude structure.

---

## 6. Why normalization is the next natural move

Assume now that a realization episode has a finite mutually exclusive endpoint set `Ω` and exactly one endpoint becomes realized.

Then any structurally acceptable rule must assign nonnegative weights `W(z)` with:

```text
Σ_{z∈Ω} W(z) = 1
```

If `I(z)` is already the canonical support scalar, the most economy-preserving move is:

```text
W(z) = I(z) / Σ_w I(w)
```

Why?
Because this introduces no new structure except normalization over the available alternatives.

Any other rule of the form:

```text
W_f(z) = f(I(z)) / Σ_w f(I(w))
```

would require an additional nonlinear choice function `f`.

Unless E₀ provides an independent structural reason for that `f`, the choice is arbitrary.

Therefore normalized intensity is the **minimal non-arbitrary rule**.

---

## 7. The key uniqueness argument

This is the strongest current argument available.

Suppose:

1. `I(z)=|Ψ(z)|²` is the canonical endpoint support scalar,
2. realization weights must be built only from canonical support,
3. no extra nonlinear distortion may be introduced without structural necessity.

Then the only admissible normalized realization rule is:

```text
P(z) = I(z) / Σ_w I(w)
```

because every alternative `f(I)` injects extra, unjustified structure.

This is not yet a theorem in the deepest sense, but it is a very strong minimality argument.

---

## 8. Why this still falls short of a full Born derivation

We must remain precise.

The above argument shows that **if** E₀ enters an exclusive bounded alternative regime, and **if** realization weights are to be assigned canonically from the amplitude object without extra assumptions, then normalized intensity is the uniquely natural candidate.

What it does **not** yet prove is that the world must always present E₀ episodes in that regime.

So the distinction is:

- **conditional necessity** inside the regime,
- not yet **universal necessity** across all E₀ domains.

That is why “Born-like” remains the right phrase.

---

## 9. The regime where Born-like normalization becomes mandatory

We can now state the regime explicitly.

### Born-Criterion Regime (proposed)

For an E₀ transition episode, a Born-like normalized intensity rule is structurally mandatory if:

1. there exists a bounded alternative endpoint set `Ω`,
2. exactly one endpoint in `Ω` becomes realized,
3. endpoint support is fully represented by the amplitude carrier `Ψ(z)`,
4. no additional endpoint-distorting rule is allowed unless independently derived.

Under these four conditions:

```text
P(z) = |Ψ(z)|² / Σ_w |Ψ(w)|²
```

is not just plausible; it is the minimal structurally non-arbitrary realization rule.

That is the sharpest statement currently justified.

## 14. Obvious next objections

Several serious questions remain.

### 14.1 Why exclusivity?

In many domains, realization may not be strictly single-endpoint. Then Born-like normalization is not the right operational semantics.

### 14.2 Why bounded alternatives?

Open-ended landscapes may not admit a stable finite endpoint set.

### 14.3 What about continuous endpoint spaces?

Then one would need an intensity density and measure-theoretic normalization.

### 14.4 Could E₀ demand a different canonical scalar in some enriched regime?

Possibly, if the carrier is enlarged beyond the current complex path object.

These are real limitations, not minor caveats.
