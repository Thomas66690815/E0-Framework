## 2. Path amplitude vs endpoint amplitude

We must separate two levels.

### 2.1 Individual path object

For a single path `p`:

```text
Ψ(p) = exp(-S(p)) exp(iΘ(p))
```

Then:

```text
|Ψ(p)| = exp(-S(p))
|Ψ(p)|² = exp(-2S(p))
```

At the single-path level, the phase disappears under modulus.
So `|Ψ(p)|²` is simply a sharper magnitude penalty than coherence `C(p)=exp(-S(p))`.

That alone is not yet very interesting.

### 2.2 Endpoint amplitude

The richer object arises when multiple admissible paths reach the same target `z`:

```text
Ψ(z) = Σ_{p→z} Ψ(p)
```

Now:

```text
I(z) = |Ψ(z)|²
```

contains cross-terms between different paths.

This is where something qualitatively new happens.

## 3. The cross-term structure

Take two contributing paths `p1, p2` to the same target `z`:

```text
Ψ(z) = Ψ(p1) + Ψ(p2)
```

Then:

```text
|Ψ(z)|² = |Ψ(p1) + Ψ(p2)|²
         = |Ψ(p1)|² + |Ψ(p2)|² + 2 Re(Ψ(p1) overline{Ψ(p2)})
```

Using:

```text
Ψ(pk) = exp(-S_k) exp(iΘ_k)
```

we get:

```text
I(z)
= exp(-2S1) + exp(-2S2) + 2 exp(-(S1+S2)) cos(Θ1-Θ2)
```

This already shows the crucial fact:

> `I(z)` is not merely accumulated burden.  
> It is burden modulated by orientational compatibility.

That is the first reason the square-modulus is special.

## 4. Why the modulus square is natural

Once `Ψ(z)` is complex-valued, there are many scalar functions one could apply.
Why should `|Ψ|²` be privileged?

### 4.1 Positivity

`|Ψ|² ≥ 0` automatically.
This matters if the result is to function as any kind of intensity, salience, realizability weight, or endpoint support measure.

### 4.2 Phase-invariant scalarization

If global phase choice is a representational redundancy, then any endpoint scalar should not depend on arbitrary overall phase rotation.

`|Ψ|²` is invariant under:

```text
Ψ → exp(iα) Ψ
```

This is a major structural virtue.

### 4.3 Cross-term retention

Unlike `|Ψ|`, the square modulus preserves the bilinear interference structure in a clean algebraic way.
It naturally exposes pairwise path interactions.

### 4.4 Additivity over orthogonal decomposition

Whenever amplitude contributions can be decomposed into mutually noninterfering sectors, the square norm is the right scalar that adds cleanly.
This is a major reason norms become central in amplitude formalisms.

## 6. Why this is not yet probability

We must remain extremely strict here.

From `I(z) = |Ψ(z)|²`, probability does **not** follow automatically.
Several missing steps remain:

1. a normalized total measure over alternatives,
2. a justification for exclusive realization semantics,
3. a rule connecting endpoint support to realized outcome frequencies,
4. and possibly a notion of repeated comparable trials.

Without those, `I(z)` is an intensity / support / salience quantity, not yet a probability law.

This distinction matters.

- dynamically changing landscapes,
- historized path suppression or amplification,

So one cannot casually divide by a total unless the relevant amplitude family is bounded and well-defined.

This means a proper E₀ derivation must specify the regime:

- bounded path family,
- bounded endpoint set,
- stabilized landscape at evaluation scale.

Only then can normalized support be considered.
